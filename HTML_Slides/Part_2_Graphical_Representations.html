Empirical CDF

Empirical CDF – Definition

Definition (the “empirical distribution function” of Part 1)

\[ F(x) \;=\; \sum_{x_i \leq x} f(x_i) \;=\; \frac{\text{number of observations} \le x}{n} \]

(the sum runs over the distinct observed values $x_i \le x$)

$F(x)$ is the share of observations that are at most $x$. Example: $F(39) = \tfrac{7}{11} = 0.6364$ – $63.6\,\%$ of the players wear size $39$ or smaller.

  • Computing the cumulative relative frequency for every observed value yields the empirical CDF
  • Between two observed values $F$ stays constant; at each observed value it jumps up by $f(x_i)$
  • Quantiles can therefore be read off directly from it

Empirical CDF – Reading Off Quantiles

Example: Median. The median is the smallest value at which the empirical CDF reaches or exceeds $0.5$:

\[ \tilde{x} = x_{0.5} = F^{-1}(0.5) = \min\{x \mid F(x) \geq 0.5\} \]

Shoe sizes: $F(38) = 0.2727 < 0.5$, but $F(39) = 0.6364 \ge 0.5$ $\;\Rightarrow\; \tilde{x} = 39$.

Generalisation

Every $p$-quantile ($0 < p \leq 1$) can be obtained from the empirical CDF:

\[ x_{p} = F^{-1}(p) = \min\{x \mid F(x) \geq p\} \]

go up to the height $p$, move right until you hit the step function and read off the $x$-value there.

Why “$\ge p$” and not “$= p$”? $F$ jumps – here it never takes the value $0.5$.

Empirical CDF – Reading Off Quantiles Graphically

$80\,\%$ quantile: $F(39) = 0.6364 < 0.8 \le F(40) = 0.8182$ $\Rightarrow x_{0.8} = 40$.
Same values as with the position rule $x_p = x_{(\lceil n \cdot p \rceil)}$ of Part 1: $\lceil 11 \cdot 0.5 \rceil = 6 \rightarrow 39$ and $\lceil 11 \cdot 0.8 \rceil = 9 \rightarrow 40$.

Histogram

The histogram is a special type of bar chart used to visualise the distribution of metric data. What makes it special is that the observed values are not displayed individually but are grouped into classes (bins/intervals).

Density

For each class, the relative frequency is computed and divided by the class width:

\[ \text{density} = \frac{\text{relative frequency of the class}}{\text{class width}} \]

The bar height equals this density, so that the area of each bar represents the proportion of observations in the corresponding class.

  • Classes are defined by interval boundaries
  • The choice of class width has a strong effect on the shape of the histogram
  • Classes of different widths are also possible

Histogram – shoe sizes (class width 2). Each dot at the top is one player; dots with an orange ring lie exactly on a class boundary. Hover over a bar: its players light up.

Histogram – Construction (Steps)

  1. Define the classes
    • Notation: $[$ = inclusive, $($ = exclusive
      • $[37,39]$: both 37 and 39 belong to the class
      • $(39,41]$: 39 does not belong, 41 does
    • Each class is open on the left and closed on the right: $(a, b]$
    • This way every value is assigned to exactly one class
    • Exception: the first class is closed on both sides $[a, b]$ so that the smallest value is not lost
    • e.g. $[37,39],\;(39,41],\;(41,43],\;(43,45],\;(45,47]$
  2. Count the observations in each class $\to$ absolute frequencies
  3. Compute the relative frequencies
  4. Divide the relative frequencies by the class width $=$ density
  5. Draw the bars with heights equal to these densities

Solution (2/3) – Car Park: Heights versus Areas

3. Twice as high $\neq$ twice as many

No. Both classes have the share $0.3$, i.e. $\mathbf{60}$ tickets each. The class $(2,4]$ is twice as wide ($2$ hours instead of $1$), so the same area needs only half the height: $0.3 / 2 = 0.15$.

4. Free parking: at most 2 hours

Durations $\le 2$ hours $=$ classes $[0,1]$ and $(1,2]$: $f_1 + f_2 = 0.25 + 0.3 = \mathbf{0.55}$, i.e. $55\,\%$ of the tickets $= 0.55 \cdot 200 = \mathbf{110}$ tickets. A ticket of exactly $2$ hours lies in $(1,2]$ and is therefore counted as free.

Read a histogram by its areas, not by its heights: share $=$ height $\cdot$ width. The height only says how densely the tickets lie per hour.

Solution (3/3) – Car Park: Python

Shares and numbers of tickets from the bar areas

f4 = 1 - f.sum()                       # all areas add up to 1: f4 = 0.15

Histograms in Python – with Our Classes

Correct: classes with pd.cut, bars with plt.bar

def density_hist(x, breaks):
    cls = pd.cut(x, breaks, right=True, include_lowest=True)
    f = pd.Series(cls).value_counts(normalize=True, sort=False)
    w = np.diff(breaks)                                  # class widths
    plt.bar(breaks[:-1], f / w, width=w, align="edge", edgecolor="black")
    return f / w                                         # densities f_j / w_j

density_hist(shoe, [37, 39, 41, 43, 45, 47])   # 0.3182 0.1364 0 0 0.0455
density_hist(shoe, [37, 39, 40, 41, 46])       # 0.3182 0.1818 0.0909 0.0182
  • right=True: classes $(a,b]$; include_lowest=True: first class closed $[a,b]$.
  • Bar heights $=$ densities $f_j/\Delta x_j$ (as in the tables), so every bar area equals $f_j$.

Lower Whisker – Computation

The lower whisker is the smallest data point that is not yet an outlier. To find it, compute a lower bound – every value below it is classified as an outlier.

\begin{align*} \text{Whisker}_{\min} &= \min\{x_i \mid x_i \ge x_{0.25} - k(x_{0.75} - x_{0.25})\} \\ &\text{with } k = 1.5 \\ &= \min\{x_i \mid x_i \ge 38 - 1.5(40 - 38)\} \\ &= \min\{x_i \mid x_i \ge 38 - 3\} \\ &= \min\{x_i \mid x_i \ge 35\} = 37 \end{align*}

Since $37$ is the smallest data value $\ge 35$, the lower whisker ends at $37$.

Lower Whisker – Step by Step

  1. Compute the IQR: the interquartile range is the difference between the 3rd and 1st quartile: $\text{IQR} = x_{0.75} - x_{0.25} = 40 - 38 = 2$
  2. Compute the lower bound: subtract $1.5$ times the IQR from the 1st quartile: $38 - 1.5 \cdot 2 = 38 - 3 = 35$
  3. Check the data: every data point below $35$ would be an outlier.
  4. Determine the lower whisker: the smallest data value still $\ge 35$ becomes the lower whisker. In our dataset this is $37$.

Interpretation

The lower whisker extends down to $37$ – the smallest value that is not classified as an outlier. If a value $< 35$ existed, it would be shown separately as an outlier in the boxplot.

Upper Whisker – Computation

The upper whisker is the largest data point that is not yet an outlier. To find it, compute an upper bound – every value above it is classified as an outlier.

\begin{align*} \text{Whisker}_{\max} &= \max\{x_i \mid x_i \le x_{0.75} + k(x_{0.75} - x_{0.25})\} \\ &\text{with } k = 1.5 \\ &= \max\{x_i \mid x_i \le 40 + 1.5(40 - 38)\} \\ &= \max\{x_i \mid x_i \le 43\} = 41 \end{align*}

Since $46 > 43$, the value $46$ is an outlier!

Upper Whisker – Step by Step

  1. Compute the IQR: the interquartile range is the difference between the 3rd and 1st quartile: $\text{IQR} = x_{0.75} - x_{0.25} = 40 - 38 = 2$
  2. Compute the upper bound: add $1.5$ times the IQR to the 3rd quartile: $40 + 1.5 \cdot 2 = 40 + 3 = 43$
  3. Check the data: every data point above $43$ would be an outlier.
  4. Determine the upper whisker: the largest data value still $\le 43$ becomes the upper whisker. In our dataset this is $41$.

Interpretation

The upper whisker extends up to $41$ – the largest value that is not classified as an outlier. Since $46 > 43$, the value $46$ lies above the upper bound and is shown as a separate point in the boxplot.

Boxplot – Interpretation (1/3): Symmetry and Median

Symmetry

A boxplot is symmetric when the median lies in the centre of the box and both whiskers have the same length. This indicates that the data are evenly distributed around the centre.

Position of the median

The median splits the box into two halves. If it does not lie in the middle, the distribution is skewed:

  • Median in the left half of the box $\rightarrow$ right-skewed (positively skewed): many small values, a few large values pull the distribution to the right.
  • Median in the right half of the box $\rightarrow$ left-skewed (negatively skewed): many large values, a few small values pull the distribution to the left.

Boxplot – Interpretation (2/3): Box and Whiskers

Length of the box (IQR)

The box contains the middle $50\,\%$ of the data – from the 1st quartile ($Q_1$) to the 3rd quartile ($Q_3$). A wide box indicates that these middle values are widely spread. A narrow box shows that half of the data lie close together.

Length of the whiskers

The whiskers extend from the box to the smallest and largest value that is not an outlier. If both whiskers are equally long, the distribution is symmetric in the tails. Different whisker lengths indicate that the data are more spread out in one direction than in the other.

Boxplot – Interpretation (3/3): Outliers

Outliers

Values that lie beyond the whiskers are shown individually as outliers. A value is considered an outlier if it lies more than $1.5$ times the IQR below $Q_1$ or above $Q_3$. Outliers can indicate measurement errors, special cases, or a strongly skewed distribution.

Example: shoe-size data

  • Box: $Q_1 = 38$, median $= 39$, $Q_3 = 40$ $\rightarrow$ the median lies in the centre, the box is symmetric.
  • Whiskers: lower whisker $= 37$, upper whisker $= 41$ $\rightarrow$ both whiskers have the same length (each 1 unit from the box).
  • Outlier: $46 > 43$ (upper bound) $\rightarrow$ despite the symmetric box, the overall boxplot is not symmetric.

Boxplot – with Labels

Switch on the lengths: both box halves and both whiskers are $1$ long – only the outlier breaks the symmetry.

Boxplot – Conclusion

Advantages of the boxplot

  • Compact display of the most important summary statistics at a glance: median, quartiles, range and outliers.
  • Allows a quick assessment of the symmetry and skewness of a distribution.
  • Especially useful for comparing several groups side by side – e.g. shoe sizes of different teams.
  • Outliers are automatically detected and made visible.

Limitation

The boxplot reveals no information about the exact shape of the distribution inside the box – two very different datasets can produce the same boxplot. To study the shape, a histogram is a useful complement.

def box_stats(x, k=1.5):                    # course quartiles + 1.5 IQR rule
    q1, med, q3 = np.quantile(x, [0.25, 0.5, 0.75], method="inverted_cdf")
    lo, hi = q1 - k * (q3 - q1), q3 + k * (q3 - q1)
    inside = x[(x >= lo) & (x <= hi)]
    return dict(q1=q1, med=med, q3=q3, whislo=inside.min(), whishi=inside.max(),
                fliers=x[(x < lo) | (x > hi)])

Which measure to report?

The mean ($7$) exceeds six of the seven values – the outlier pulls it up. Median ($4$) and trimmed mean ($4.2$) are robust $\rightarrow$ report the median (or the trimmed mean).

def box_stats(x, k=1.5):
    q1, med, q3 = np.quantile(x, [0.25, 0.5, 0.75], method="inverted_cdf")
    lo, hi = q1 - k * (q3 - q1), q3 + k * (q3 - q1)     # fences
    inside = x[(x >= lo) & (x <= hi)]
    return dict(q1=q1, med=med, q3=q3, whislo=inside.min(), whishi=inside.max(),
                fliers=x[(x < lo) | (x > hi)])

Summary (1/4) – Empirical CDF

Definition

\[ F(x) \;=\; \sum_{x_i \leq x} f(x_i) \qquad \text{with values in } [0,1] \]

Reading off quantiles

\[ x_{p} = F^{-1}(p) = \min\{x \mid F(x) \geq p\}, \qquad 0 < p \leq 1 \]

Special case: $F^{-1}(0.5) = \tilde{x}$ (median); same as the position rule $x_{(\lceil n \cdot p \rceil)}$.

  • Step function showing the cumulative relative frequency; jump height at $x_i$ equals $f(x_i)$.
  • Shares: $F(x)$ = share of values $\le x$; share in $(a,b]$ $= F(b) - F(a)$.

Summary (2/4) – Histogram

Density of a class

\[ \text{density}_j \;=\; \frac{f_j}{\Delta x_j} \;=\; \frac{\text{rel.\ frequency of class } j}{\text{class width}} \]

Area = relative frequency

\[ \text{area}_j \;=\; \text{density}_j \cdot \Delta x_j \;=\; f_j, \qquad \sum_j f_j = 1 \]

  • Suitable for metric, classified data.
  • Classes $[c_0,c_1],\,(c_1,c_2],\,\ldots,\,(c_{k-1},c_k]$ with boundaries $c_0 < \ldots < c_k$.
  • The choice of class width strongly affects the shape.
  • Unequal class widths are possible – heights remain densities; the highest bar need not hold the most values.

Summary (3/4) – Boxplot

Five-number summary

\[ x_{\min}\ \text{(or lower whisker)},\ x_{0.25},\ \tilde{x},\ x_{0.75},\ x_{\max}\ \text{(or upper whisker)} \]

\[ \text{IQR} \;=\; x_{0.75} - x_{0.25} \]

Whisker bounds (Tukey, $k = 1.5$)

\begin{align*} \text{Whisker}_{\min} &\;=\; \min\!\bigl\{x_i \mid x_i \geq x_{0.25} - k \cdot \text{IQR}\bigr\} \\ \text{Whisker}_{\max} &\;=\; \max\!\bigl\{x_i \mid x_i \leq x_{0.75} + k \cdot \text{IQR}\bigr\} \end{align*}

Outliers

All values $< x_{0.25} - 1.5 \cdot \text{IQR}$ or $> x_{0.75} + 1.5 \cdot \text{IQR}$ are displayed individually as outliers.
