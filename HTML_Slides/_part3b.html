The $p$-value – intuition

A single question

“How surprising are my data if $H_0$ were true?”

  • Small $p$-value ($\approx 0$): such an extreme result would be very rare under $H_0$ $\Rightarrow$ doubt about $H_0$.
  • Large $p$-value ($\approx 1$): the data are unsurprising under $H_0$ $\Rightarrow$ no reason to doubt it (but not positive proof of $H_0$).

The $p$-value measures how surprising the data are if $H_0$ holds – the smaller, the stronger the evidence against $H_0$.

The $p$-value – graphically

The (two-sided) $p$-value is the total area in both tails that is at least as extreme as the observed value. Drag the blue handle; switch $H_1$ to see the one‑sided tail.

The $p$-value – definition

Definition

The $p$-value is the probability, under the validity of $H_0$, of observing a test statistic that is at least as extreme as the one actually observed.

  • “At least as extreme” is set by $H_1$: two-sided ($\mu\neq\mu_0$) $=$ both tails $|Z|\ge|Z_n|$; one-sided $=$ only the tail in the $H_1$ direction. Same statistic, different $p$.
  • $0 \le p \le 1$; software (e.g. scipy.stats) always reports it.
  • Advantage: more informative than a bare yes/no – it quantifies the strength of the evidence.
Talk track: read the definition twice, slowly – every word carries weight. “Under the validity of $H_0$” = we compute in the $H_0$ world. “At least as extreme” = the observed value or anything further out, where “out” is defined by $H_1$. Warn explicitly: the $p$-value is NOT the probability that $H_0$ is true – that misreading is the single most common exam error (dedicated slide follows).

Decision rule

One rule for all tests

\[ p < \alpha \;\Longrightarrow\; \text{reject } H_0 \qquad\qquad p \ge \alpha \;\Longrightarrow\; \text{keep } H_0 \]

  • Left: $p$ large, value in the acceptance region.
  • Right: $p$ small, value in the rejection region.
  • $\alpha$ is the “benchmark”.

Drag either handle across the grey critical value; move $\alpha$ to shift the benchmark.

Two rules, one decision: critical value $\leftrightarrow$ $p$-value

  • $\alpha$ = tail area beyond the critical value (fixed in advance).
  • $p$ = tail area beyond your observed statistic.
  • Statistic past the bar $\Leftrightarrow$ its tail is smaller $\Leftrightarrow p<\alpha$.
  • Picture: right-sided test ($z_{0.95}=1.645$); two-sided: both tails, $z_{0.975}=1.96$.

The two decision rules are identical: “test statistic beyond the critical value” and “$p<\alpha$” always agree – the critical value is simply the statistic whose tail area equals $\alpha$.

Both rules, one verdict – worked example

Cream, two-sided, known $\sigma$:   $Z_n=-2.125$,   $\alpha=0.05$.

Critical-value rule

\[ |Z_n| = 2.125 \;>\; 1.96 = z_{0.975} \]

$\Rightarrow$ reject $H_0$.

$p$-value rule

\[ p = 2\,\Phi(-2.125) = 0.034 \]

$0.034 < 0.05 \Rightarrow$ reject $H_0$.

Same data, same $\alpha$, same decision – because $|Z_n|>z_{0.975}$ and $p<\alpha$ are just two ways of saying the observed value sits past the bar.

Solution – $p$-value and $\alpha$

Rule: two-sided $p=2\,\Phi(-|Z_n|)=2\,\bigl(1-\Phi(|Z_n|)\bigr)$ (symmetry); reject $H_0$ if $p<\alpha$.

\[ p = 2\,\bigl(1-\Phi(1.85)\bigr) = 2\cdot 0.0322 = \mathbf{0.0644} \qquad(\text{exact, unrounded }\Phi\text{: }0.0643) \]

  • At $\alpha = 0.05$:   $0.0644 > 0.05 \Rightarrow$ keep $H_0$.   Check: $|Z_n|=1.85<1.96=z_{0.975}$.
  • At $\alpha = 0.10$:   $0.0644 < 0.10 \Rightarrow$ reject $H_0$.   Check: $|Z_n|=1.85>1.645=z_{0.95}$ (two‑sided at $10\,\%$ uses $z_{1-0.10/2}=z_{0.95}$).

The same data can be “significant” or not – $\alpha$ must be fixed in advance, never chosen to fit the result.

Computing the $p$-value (two-sided)

Known variance

\[ p = 2\cdot\Phi\!\bigl(-|Z_n|\bigr) = P\!\bigl(|Z| > |Z_n|\bigr), \quad Z\sim N(0,1) \]

Unknown variance

\[ p = 2\cdot F_{t,n-1}\!\bigl(-|T_n|\bigr) \]

Why double? With $H_1:\mu\neq\mu_0$ a deviation in either direction counts, so “at least as extreme” means both tails $|Z|>|Z_n|$; by symmetry each has area $\Phi(-|Z_n|)$ – hence the factor $2$. (One-sided: a single tail, no doubling.)

\begin{align*} p &= 2\cdot F_{t,8}(-0.7947)\\ &= 2\cdot 0.22485 = 0.4497 \end{align*}

$p$-values with Python

import numpy as np
from scipy import stats
milk = np.array([1005, 1001, 997, 1000, 1001, 998, 999, 999, 1009])
cream = np.array([251, 248, 248, 249, 250, 251, 247, 246,
                  252, 251, 248, 247, 246, 249, 248, 252])
for x, mu0, sigma in [(milk, 1000, 3), (cream, 250, 2)]:
    n = len(x)
    z = (x.mean() - mu0) / (sigma / np.sqrt(n))           # sigma known
    t = (x.mean() - mu0) / (x.std(ddof=1) / np.sqrt(n))   # sigma estimated
    p_z = 2 * stats.norm.sf(abs(z))                       # 2 * (1 - Phi(|z|))
    p_t = 2 * stats.t.sf(abs(t), df=n - 1)                # 2 * (1 - F_t,n-1(|t|))
    print(f"z = {z:.4f}, p = {p_z:.4f} | t = {t:.4f}, p = {p_t:.4f}")

Output (milk, cream):

z = 1.0000, p = 0.3173 | t = 0.7947, p = 0.4497
z = -2.1250, p = 0.0336 | t = -2.1086, p = 0.0522

sf $=1-F$ (survival function). The $t$-row equals ttest_1samp(x, mu0).

$p$-value – typical misconceptions

What the $p$-value is not

  • Not the probability that $H_0$ is true.
  • A large $p$-value does not prove $H_0$ – it only shows no contradiction.

Correct – mind the direction

The $p$-value is the probability of the data (or more extreme) assuming $H_0$ (chance) holds: $P(\text{data}\mid H_0)$. It conditions on chance; it does not give the probability that chance was the cause, $P(H_0\mid\text{data})$.

Talk track: use the courtroom again – $P(\text{evidence}\mid\text{innocent})$ is not $P(\text{innocent}\mid\text{evidence})$. Concrete anchor: “the probability that a randomly tested person has these symptoms IF healthy” vs. “the probability the person is healthy GIVEN the symptoms” – clearly different. Also stress the second bullet: a large $p$ means the data cannot distinguish $H_0$ from nearby alternatives – absence of evidence, not evidence of absence.

Significant $\neq$ important – the large-$n$ trap

The $p$-value measures evidence, not size

With enough data, any tiny deviation from $\mu_0$ becomes statistically significant – even one that is practically irrelevant.

Milk machine, observed $\bar x = 1000.2$ ml ($\mu_0=1000$, $\sigma=3$)

$Z_n$$p$ (two-sided)verdict at $\alpha=0.05$
$n=9$$0.20$$0.84$not significant
$n=10\,000$$6.67$$<0.0001$highly significant

The same irrelevant $0.2$ ml deviation – invisible at $n=9$, “highly significant” at $n=10\,000$. So report the effect size and the CI, not just $p$.

Talk track: significance answers “is there evidence of ANY deviation?”, not “is the deviation large enough to matter?”. With $n=10\,000$ the SE is $0.03$ ml – the test becomes a microscope. Flip side (links to power): with small $n$, even an important deviation often stays invisible. Practical rule for the students: $p$-value for evidence, CI for magnitude – always read both.

Two ways to be wrong

Intuition

Like a smoke detector, we can be wrong in two ways: false alarm or missed fire.

Decision$H_0$ true$H_0$ false
reject $H_0$Type I error ($\alpha$)correct (power $1-\beta$)
keep $H_0$correct ($1-\alpha$)Type II error ($\beta$)

Type I error = false alarm (reject although $H_0$ is true).    Type II error = miss (keep although $H_1$ is true).

Talk track: build the table column by column – “first fix the TRUE state of the world (column), then look at what our test DID (row).” Smoke detector: too sensitive = many false alarms (Type I); too sluggish = missed fire (Type II). Make students say which error the milk test could have made (it kept $H_0$, so only a Type II is possible). Common confusion: thinking both errors can occur in the same test run – only one column is ever real.

$\alpha$ and $\beta$ in a picture

  • The two curves show the standardised $\bar X$ in each “world”: left centred at $\mu_0$ (value $0$, if $H_0$ holds), right at the true $\mu_1$ (here $2.6$ standard errors above $\mu_0$, if $H_1$); the red line is the critical value of a right-sided test ($1.645$).
  • $\alpha$: $H_0$ true, but beyond the critical value.
  • $\beta$: $H_1$ true, but on this side.
  • The distributions overlap – both errors cannot be $0$ at once.

Sliders: a smaller $\alpha$ moves the red line right ($\beta$ grows); a larger effect or a larger $n$ pulls the $H_1$ curve away ($\beta$ shrinks).

Type I error ($\alpha$) – controllable

Definition

\[ P(\text{reject } H_0 \mid H_0 \text{ true}) = \alpha \]

  • Directly controllable through the choice of $\alpha$ (typically $0.05$).
  • In $5\,\%$ of cases a true $H_0$ is wrongly rejected.

Milk

$H_0:\mu=1000$ is true, yet the test rejects (false alarm) – probability $=\alpha$.

Type II error ($\beta$) – only indirectly influenced

Definition (at a specific alternative $\mu_1$)

\[ P(\text{keep } H_0 \mid \mu = \mu_1) = \beta \]

  • No direct lever; $\beta$ depends on:
    • $\alpha$, sample size $n$, spread $\sigma^2$,
    • true deviation $|\mu-\mu_0|$ (effect size).
  • At a fixed $\mu_1$: smaller $\alpha$ $\Rightarrow$ higher bar $\Rightarrow$ more misses ($\beta$ rises);   larger $n$ $\Rightarrow$ smaller SE $\Rightarrow$ $\beta$ falls.

Power $=1-\beta$: the ability to actually reject a false $H_0$.

Only one error is controllable

Question: Which error can we only make when we reject $H_0$?

Answer

The Type I error – and that is exactly the one we control via $\alpha$.

Consequence for the choice of hypotheses

This is why the claim you want to establish goes into $H_1$ (rule of thumb from above): wrongly declaring it “established” – rejecting $H_0$ although $H_0$ holds – is the costly mistake, and exactly this one is the controllable Type I error.

Summary 1 – foundations

Normal distribution

$X\sim N(\mu,\sigma^2)$   $\Rightarrow$   $Z=\dfrac{X-\mu}{\sigma}\sim N(0,1)$

$P(X\le x)=\Phi\bigl(\tfrac{x-\mu}{\sigma}\bigr)$,    $\Phi(-z)=1-\Phi(z)$

quantile: $x_p=\mu+\sigma\,z_p$,    $z_{0.975}=1.96$

Sampling distribution of $\bar X$

$E(\bar X)=\mu$,    $\mathrm{Var}(\bar X)=\sigma^2/n$,    $\mathrm{SE}=\sigma/\sqrt n$

normal data: $\bar X\sim N(\mu,\sigma^2/n)$ exactly;

otherwise (CLT, $n\gtrsim30$): approximately.

Every interval and test in this part standardises $\bar X$ with its standard error – and the CLT makes this work even for non-normal data.

Summary 2 – confidence intervals

Known variance $\sigma$    ($Z_n\sim N(0,1)$)

\[ \text{CI}_{1-\alpha} = \left[\bar{X}-z_{1-\alpha/2}\frac{\sigma}{\sqrt{n}},\; \bar{X}+z_{1-\alpha/2}\frac{\sigma}{\sqrt{n}}\right] \]

Unknown variance    ($T_n\sim t_{n-1}$)

\[ \text{CI}_{1-\alpha} = \left[\bar{X}-t_{1-\alpha/2,\,n-1}\frac{s}{\sqrt{n}},\; \bar{X}+t_{1-\alpha/2,\,n-1}\frac{s}{\sqrt{n}}\right] \]

Sample size for a margin of error $e$ (known $\sigma$):   $n\ge\bigl(z_{1-\alpha/2}\,\sigma/e\bigr)^2$, rounded up.

Summary 3 – hypothesis test (two-sided)

$H_0:\mu=\mu_0$ vs. $H_1:\mu\ne\mu_0$

Test statistics

\[ Z_n = \frac{\bar{X}-\mu_0}{\sigma/\sqrt{n}}\sim N(0,1),\qquad T_n = \frac{\bar{X}-\mu_0}{s/\sqrt{n}}\sim t_{n-1} \qquad(\text{under } H_0) \]

Decision

Reject if $|Z_n|>z_{1-\alpha/2}$ ($\sigma$ known) or $|T_n|>t_{1-\alpha/2,\,n-1}$ ($\sigma$ unknown).

One idea behind every formula

$p$ = probability, if $H_0$ were true, of a value at least as extreme as observed – in the direction(s) that $H_1$ allows.

An estimator $\hat\theta=\hat\theta(X_1,\dots,X_n)$ is a random variable; its value for the observed sample is the estimate.

Why divide by $n-1$ in $s^2$?

Sample variance – unbiased

\[ s^2=\frac{1}{n-1}\sum_{i=1}^n\bigl(X_i-\bar X\bigr)^2, \qquad E(s^2)=\sigma^2 . \]

  • We measure the spread around the estimated mean $\bar X$, which sits in the middle of the data – so the squared deviations come out systematically too small.
  • Dividing by $n$ would give $E\bigl(\tfrac1n\sum(X_i-\bar X)^2\bigr)=\tfrac{n-1}{n}\,\sigma^2$ – biased downwards; dividing by $n-1$ corrects exactly this.
  • Estimating $\mu$ “uses up” one degree of freedom – the same $n-1$ as in $t_{n-1}$.

Simulation: $100\,000$ samples of size $n=4$ from $N(50,\,5^2)$, i.e. $\sigma^2=25$

Average of $s^2$ with $n-1$: $\mathbf{24.97}$    vs.    with $n$: $\mathbf{18.73}$   ($\approx\tfrac34\cdot25=18.75$).

The law of large numbers – intuition

Die example: a fair die has $E(X)=3.5$. After a few rolls the running mean $\bar x_n$ still jumps around; after many rolls it settles down at $3.5$.

The sample mean $\bar X_n$ gets ever more reliably close to the expected value as $n$ grows.

Twelve sequences of die rolls (grey), one highlighted (blue). The funnel $\mu\pm1.96\,\sigma/\sqrt n$ narrows: $\pm1.06$ at $n=10$, $\pm0.33$ at $n=100$, $\pm0.11$ at $n=1000$.

The law of large numbers – formal statement

Weak law of large numbers

For i.i.d. $X_i$ with $E(X_i)=\mu$ and $\mathrm{Var}(X_i)=\sigma^2<\infty$:

\[ \lim_{n\to\infty}P\bigl(|\bar X_n-\mu|>c\bigr)=0 \quad\text{for every } c>0, \qquad\text{i.e.}\quad \bar X_n\xrightarrow{\;P\;}\mu . \]

Choose any tolerance $c$, however small: the probability that $\bar X_n$ misses $\mu$ by more than $c$ goes to zero.

Why? Chebyshev's inequality: $P(|\bar X_n-\mu|>c)\le\mathrm{Var}(\bar X_n)/c^2=\sigma^2/(n\,c^2)\to0$.

Special case: relative frequencies (Bernoulli)

$X_i=1$ if an event occurs (probability $p$), else $0$: then $\bar X_n$ is the event's relative frequency, and $\bar X_n\xrightarrow{P}p$ – the basis of the frequentist view used throughout this part.

LLN: $\bar X_n$ approaches $\mu$.   CLT: how the remaining fluctuation around $\mu$ is distributed.

When only one direction matters

The idea

In a two-sided test any departure from $\mu_0$ counts against $H_0$. Often, though, a deviation is a problem in only one direction – the other direction is harmless or even welcome.

Too little in the bottle

For consumer protection only underfilling ($\mu<1000$) is critical – overfilling does not harm the customer.

Unemployment insurance

Only if the rate exceeds a threshold do contributions fall short. A lower rate causes no problem.

The question – not the data – decides the direction. The deviation we truly care about defines $H_1$, and the whole $\alpha$ goes on that one side instead of $\alpha/2$ on each.

The golden rule of one-sided tests

If you remember only one sentence

We reject $H_0$ when the sample result is sufficiently extreme in the direction specified by the alternative hypothesis $H_1$.

$H_1:\mu<\mu_0$ (smaller) reject if $z$ very negative $H_1:\mu>\mu_0$ (larger) reject if $z$ very positive $H_1:\mu\neq\mu_0$ (different) reject if $|z|$ very large (either way)

The inequality in $H_1$ points straight at the rejection region (orange): “$<$” $\to$ left tail, “$>$” $\to$ right tail, “$\neq$” $\to$ both.

The price: you must commit in advance

The direction is part of the hypothesis

Choose one- vs. two-sided before looking at the data – based on the research question alone.

  • Picking the side after seeing which way the data point inflates the true Type I error from $\alpha$ to as much as $2\alpha$.
  • A one-sided test is blind to deviations in the other direction: even a large effect on the “wrong” side never rejects $H_0$.
  • If both directions genuinely matter, use a two-sided test.

One-sided tests buy power with a promise – that the other direction really does not matter.

One-sided $p$-value – mind the sign

Only the $H_1$-tail counts

The one-sided $p$-value is the probability, under $H_0$, of a value at least as far in the $H_1$ direction as the one observed. The opposite tail is irrelevant – a deviation there supports $H_0$.

Sign check – a big $|z|$ in the wrong direction is not significant

Right-sided test with $z=-2.5$: the statistic is on the $H_0$ side, so $p = 1-\Phi(-2.5) = 0.994 > 0.5$ – you never reject, even though $|z|$ is large. Check the data point in the $H_1$ direction before computing.

Link to two-sided: if the deviation is in the $H_1$ direction, $p_{\text{one}} = p_{\text{two}}/2$; otherwise $p_{\text{one}} = 1-p_{\text{two}}/2$.

The classic trap: a right-sided test with a negative $T_n$. Say: “if your statistic is on the $H_0$ side, $p>0.5$ – stop, you can never reject.” Always check the statistic points the $H_1$ way before computing the tail area.

In contrast to the two-sided test ($p=0.0522$), the left-sided test is significant here – because the whole $\alpha$ lies on the critical side.

Exercise – one- vs. two-sided on the same data

A coating must exceed a target thickness. A test gives $T_n = 1.80$ with df $=15$. Compare the right-sided and the two-sided decision at $\alpha = 0.05$ – with the $p$-value and with the critical value.

Hint: $1-F_{t,15}(1.80) = 0.0460$;   $t$-table, row df $=15$.

Solution – one- vs. two-sided

Rule: one-sided $p$ $=$ the single tail in the $H_1$ direction; two-sided $p$ $=$ both tails $=2\times$ the one-sided value (here $T_n$ points in the $H_1$ direction).

\begin{align*} \text{right-sided:}\ & p = 1-F_{t,15}(1.80) = \mathbf{0.0460} < 0.05 \;\Rightarrow\; \text{reject}\\ \text{two-sided:}\ & p = 2\cdot 0.0460 = \mathbf{0.0920} > 0.05 \;\Rightarrow\; \text{keep} \end{align*}

Check with the critical values ($t$-table, row df $=15$): right-sided $T_n=1.80>1.753=t_{0.95;\,15}$ $\Rightarrow$ reject;   two-sided $|T_n|=1.80<2.131=t_{0.975;\,15}$ $\Rightarrow$ keep – the same verdicts.

Identical data, opposite decisions. The one-sided test is more powerful in the chosen direction – exactly why the direction must be fixed before seeing the data.

One-sided confidence intervals

  • A one-sided test has a one-sided CI – only one bound, the other is $\pm\infty$.
  • scipy reports them with low=-inf or high=inf, i.e. $(-\infty;\,x]$ or $[x;\,+\infty)$.

Calculation (known variance)

\begin{align*} \text{left-sided test } (H_1:\mu<\mu_0):\quad & \Bigl(-\infty,\ \bar X + z_{1-\alpha}\tfrac{\sigma}{\sqrt n}\Bigr]\\ \text{right-sided test } (H_1:\mu>\mu_0):\quad & \Bigl[\bar X - z_{1-\alpha}\tfrac{\sigma}{\sqrt n},\ +\infty\Bigr) \end{align*}

For unknown variance: replace $z_{1-\alpha}$ by $t_{1-\alpha,\,n-1}$.

Note the one-sided quantile $z_{1-\alpha}$ (not $z_{1-\alpha/2}$) – the whole $\alpha$ sits on one side, exactly as in the test.

One-sided CIs – milk and cream (known)

CI for the left-sided test: upper bound ($z_{0.95}=1.645$):

\begin{align*} \text{Milk:}\; & 1001 + 1.645\cdot\tfrac{3}{\sqrt{9}} = 1002.645\\ \text{Cream:}\; & 248.9375 + 1.645\cdot\tfrac{2}{\sqrt{16}} = 249.760 \end{align*}

CI for the right-sided test: lower bound:

\begin{align*} \text{Milk:}\; & 1001 - 1.645\cdot\tfrac{3}{\sqrt{9}} = 999.355\\ \text{Cream:}\; & 248.9375 - 1.645\cdot\tfrac{2}{\sqrt{16}} = 248.115 \end{align*}

If $\mu_0$ lies beyond the single bound, $H_0$ is rejected.

Exercise – muesli filling (exam-style, one-sided $t$-test)

A plant fills muesli into packs with target weight $\mu_0=250$ g. Overfilling costs money, so management asks: does the plant fill more than $250$ g on average? After maintenance, a sample of $n=25$ packs gives $\bar x=252.6$ g and $s=5.0$ g; $\alpha=0.05$.

Table values: $t_{0.95;\,24}=1.7109$, $t_{0.975;\,24}=2.0639$, $t_{0.99;\,24}=2.4922$, $t_{0.995;\,24}=2.7969$;   $\Phi(2.60)=0.9953$.

  1. State the hypotheses.
  2. Compute the standard error, the test statistic and the critical value, and decide.
  3. Which Python command performs this test for a data vector x?
  4. Bracket the $p$-value with the $t$-table, and approximate it with the normal distribution.
  5. Compute the (two-sided) $95\,\%$ CI for $\mu$.
  6. Decide without new calculation whether $H_0:\mu=253$ is rejected by a two-sided test at $\alpha=0.05$.

Solution (1/3) – muesli: hypotheses and test

a) The claim to be established (overfilling) goes into $H_1$ $\Rightarrow$ right-sided:

\[ H_0:\mu=250 \qquad\text{vs.}\qquad H_1:\mu>250 \]

b) $\sigma$ unknown $\Rightarrow$ $t$-test with df $=n-1=24$:

\[ \frac{s}{\sqrt n}=\frac{5.0}{\sqrt{25}}=\mathbf{1.0\ g},\qquad T_n=\frac{252.6-250}{1.0}=\mathbf{2.60},\qquad \text{critical value } t_{0.95;\,24}=\mathbf{1.7109} \]

One-sided: the whole $\alpha$ sits in the right tail, so the $0.95$-quantile (not $0.975$).

Decision

$T_n=2.60>1.7109$ $\Rightarrow$ $H_0$ is rejected: the plant fills significantly more than $250$ g on average – it should be readjusted.

Solution (2/3) – muesli: Python and the $p$-value

c) and the exact $p$-value from the summary figures:

d) $T_n$ lies between the $0.99$- and the $0.995$-quantile:

\[ t_{0.99;\,24}=2.4922 \;<\; 2.60 \;<\; 2.7969=t_{0.995;\,24} \;\Longrightarrow\; \mathbf{0.005<p<0.01} \]

One-sided: the upper-tail areas $0.01$ and $0.005$ are the bounds – no doubling (exact: $p=0.0079$).

Normal approximation: $p\approx1-\Phi(2.60)=1-0.9953=\mathbf{0.0047}$ – smaller than the exact $0.0079$, because the $t$-distribution has heavier tails. Both are far below $0.05$: same decision.

Solution (3/3) – muesli: CI and duality

\[ \textbf{e)}\quad 252.6\pm2.0639\cdot1.0=252.6\pm2.0639 \ \Rightarrow\ \text{CI}_{0.95}=\mathbf{[\,250.54\,;\,254.66\,]}\ \text{g} \]

f) The two-sided CI contains exactly the values $\mu_0$ that a two-sided test does not reject:

\[ 250.54<253<254.66 \ \Rightarrow\ H_0:\mu=253 \text{ is \textbf{not} rejected.} \]

Every $\mu_0<250.54$ or $\mu_0>254.66$ would be rejected – e.g. $\mu_0=250$.

Careful with the duality

The two-sided CI belongs to the two-sided test. The partner of the right-sided test in b) is the one-sided CI $[\,252.6-1.7109\cdot1.0\,;\,\infty)=[\,250.89\,;\,\infty)$ – it excludes $250$, consistent with the rejection.

The normal approximation shows nicely why the $t$-tails are heavier.

Trade-off and power

  • $\alpha\!\downarrow \Rightarrow \beta\!\uparrow$ (trade-off).
  • Larger $n$ raises power at every $\mu\neq\mu_0$ (at $\mu_0$ it stays at $\alpha$) – more power at the same level.
  • Power rises with the true deviation.

Drag the grey handle on the deviation axis; at $2$ SE (milk, $n=9$ vs. $36$) the curves give $0.516$ and $0.979$. Lower $\alpha$ and both curves drop.

Practice

Typically $\alpha=0.05$ and desired power $1-\beta\ge 0.80$. A power analysis provides the required $n$.

Computing $\beta$ concretely – milk

Setup: $H_0:\mu=1000$ vs. $H_1:\mu\neq1000$, $\sigma=3$, $n=9$ ($\mathrm{SE}=1$), $\alpha=0.05$.

Step 1 – turn “$|Z_n|\le1.96$” into bounds on $\bar X$: $\mu_0\pm1.96\cdot\mathrm{SE}=1000\pm1.96=[998.04\,;\,1001.96]$.

Step 2 – the truth is $\mu_1=1002$; find how often $\bar X$ still lands in that region, standardising with $\mu_1$:

\begin{align*} \beta &= P\bigl(998.04 \le \bar X \le 1001.96 \;\big|\; \mu=1002\bigr)\\ &= \Phi\!\bigl(\tfrac{1001.96-1002}{1}\bigr) - \Phi\!\bigl(\tfrac{998.04-1002}{1}\bigr) = 0.484 \end{align*}

Result

Power $=1-\beta = 0.516$: a true deviation of $2$ ml is detected with $n=9$ in only just over half the cases.

Talk track: the key move is the change of world. Step 1 lives in the $H_0$ world (where the acceptance region was built); step 2 asks how often $\bar X$ lands in that same region when the TRUTH is $\mu_1=1002$ – so we standardise with $1002$, not $1000$. Students often reuse $\mu_0$ in step 2; catch that explicitly. The sobering message: with $n=9$, a real 2 ml error escapes detection almost half the time.

Four levers for more power

More sample size helps decisively. Same situation with $n=36$ instead of $9$:

\[ \text{SE}=\tfrac{3}{\sqrt{36}}=0.5 \;\Rightarrow\; \beta = 0.021,\quad \text{power}=0.979. \]

Levers of power $1-\beta$

  1. Sample size $n\uparrow$ (strongest lever).
  2. Effect size $|\mu_1-\mu_0|$ (given).
  3. Spread $\sigma\downarrow$ (e.g. measure more precisely).
  4. Level $\alpha\uparrow$ (buys more Type I error).

Quadrupling $n$ from $9$ to $36$ raises the power from $0.52$ to $0.98$.

Talk track: go through the four levers and ask for each “who controls this?” – $n$: the researcher (budget); effect size: nature/the question; $\sigma$: partly the lab (better instruments); $\alpha$: the convention, and raising it is usually unacceptable. So in practice power planning $=$ sample size planning. Connect back to the CI length slide: same logic, $1/\sqrt n$.

$\beta$ and power with Python

import numpy as np
from scipy import stats
from statsmodels.stats.power import NormalIndPower
for n in (9, 36):                        # milk: mu0 = 1000, true mu1 = 1002, sigma = 3
    se = 3 / np.sqrt(n)
    lo, hi = 1000 - 1.96 * se, 1000 + 1.96 * se         # acceptance region (H0 world)
    beta = stats.norm.cdf(hi, 1002, se) - stats.norm.cdf(lo, 1002, se)  # mu1 world
    print(f"n = {n}: beta = {beta:.3f}, power = {1 - beta:.3f}")
pw = NormalIndPower()                    # power of the z-test; ratio=0: one sample
pw.power(effect_size=2/3, nobs1=9, alpha=0.05, ratio=0)              # 0.516
pw.solve_power(effect_size=2/3, power=0.80, alpha=0.05, ratio=0)     # 17.66 -> n = 18

Output

n = 9: beta = 0.484, power = 0.516
n = 36: beta = 0.021, power = 0.979

Effect size $d=|\mu_1-\mu_0|/\sigma=2/3$. solve_power does the power analysis: $80\,\%$ power needs at least $n=18$ bottles.

Exercise – compute $\beta$ and power (two-sided)

Test $H_0:\mu = 100$ vs. $H_1:\mu\neq 100$, known $\sigma = 10$, $n=25$, $\alpha=0.05$. The true mean is actually $\mu_1 = 105$. Find the Type II error $\beta$ and the power.

Step 1: the acceptance region for $\bar X$ under $H_0$.

Solution – $\beta$ and power (two-sided)

$\text{SE} = 10/\sqrt{25} = 2$. Acceptance region: $100 \pm 1.96\cdot 2 = [96.08\,;\,103.92]$.

\begin{align*} \beta &= P(96.08 \le \bar X \le 103.92 \mid \mu = 105)\\ &= \Phi\!\Big(\tfrac{103.92-105}{2}\Big) - \Phi\!\Big(\tfrac{96.08-105}{2}\Big) = \Phi(-0.54) - \Phi(-4.46)\\ &= 0.2946 - 0.0000 = \mathbf{0.2946} \end{align*}

Power

$1-\beta = \mathbf{0.7054}$: a true shift of $5$ units is detected in about $71\,\%$ of samples.
